# EdCoach AI Documentation

## Quick Start

🚀 **New to the project?** This documentation is organized into three comprehensive files that contain all the information you need.

## Documentation Structure

### 📊 [Complete Business Context](./business/complete-business-context.md)
Everything related to business strategy, user understanding, and product vision:
- Project vision, mission, and strategic direction
- Detailed user personas and target audience definitions  
- Complete user experience flows and journey mapping
- Strategic priorities and success metrics

### 🔧 [Complete Technical Context](./technical/complete-technical-context.md)
Everything related to system architecture, code organization, and technical implementation:
- System architecture and technology stack
- Code structure and file organization patterns
- Error handling and performance guidelines
- Implementation standards and development workflow

### 🎨 [Complete Design System](./design/complete-design-system.md)
Everything related to visual design, UI components, and user experience:
- Design guidelines and visual principles
- Component library specifications and usage
- Typography, colors, and interaction patterns
- Implementation guidelines for developers

## Role-Based Quick Start

### For Product Managers
Start with **[Complete Business Context](./business/complete-business-context.md)** for strategic overview, then reference technical and design documents as needed.

### For System Architects  
Start with **[Complete Technical Context](./technical/complete-technical-context.md)** for system understanding, then reference business context for requirements.

### For UX/UI Designers
Start with **[Complete Design System](./design/complete-design-system.md)** for design patterns, then reference business context for user understanding.

### For Developers
Start with **[Complete Technical Context](./technical/complete-technical-context.md)** for implementation guidance, then reference design system for UI components.
