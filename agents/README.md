# EdCoach AI Agent Instructions

## Agent Roles

This directory contains comprehensive system instructions for each specialized AI agent role in the EdCoach AI development team.

### 🎯 Product Manager
- **File**: `product-manager-system-instructions.md`
- **Focus**: Feature requirements, user stories, backlog prioritization
- **Key Responsibilities**: User experience, business value, growth loop optimization

### 🏗️ System Architect
- **File**: `system-architect-instructions.md`
- **Focus**: Technical architecture, system design, technology decisions
- **Key Responsibilities**: Scalability, maintainability, integration patterns

### ⚙️ Senior Backend Engineer
- **File**: `senior-backend-engineer-instructions.md`
- **Focus**: Convex backend, APIs, data management, AI integration
- **Key Responsibilities**: Server-side logic, database operations, performance

### 🎨 Senior Frontend Engineer
- **File**: `senior-frontend-engineer-system-instructions.md`
- **Focus**: React, Next.js, UI implementation, user interactions
- **Key Responsibilities**: Component development, state management, performance

### 🎨 UX/UI Designer
- **File**: `ux-ui-designer-system-instructions.md`
- **Focus**: Design system, user experience, visual specifications
- **Key Responsibilities**: Design consistency, accessibility, user flows

## Usage

Each agent instruction file provides:
- Role-specific guidelines and best practices
- Technology stack expertise
- Implementation patterns and standards
- Quality assurance requirements
- Integration points with other agents

## Coordination

When working on complex features, agents should coordinate according to the orchestration patterns defined in the main project documentation.
